# PixArc 🎨

**PixArc** is a modern web-based tool for creating stunning circular pie-slice layouts from your images. It automatically extracts vibrant color palettes from your uploads and arranges them into a beautiful, dynamic composition.

[**Live Demo (Vercel)**](https://pix-arc.vercel.app/)

![PixArc Logo](/vite.svg)

## ✨ Features

- **Circular Layouts:** Beautiful pie-slice arrangement of images.
- **Auto Color Extraction:** Uses Color Thief to automatically select harmonizing colors from your images.
- **Dynamic Scaling:** Responsive canvas that adapta to your workspace.
- **High-Resolution Export:** Export your creations in HD, 2K, or 4K for wallpapers or lock screens.
- **Multiple Layout Modes:**
  - Free Canvas
  - PC Desktop (1920x1080)
  - Phone Lock Screen (1080x1920)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/karthi-reddy-z/PixArc.git
   ```
2. Navigate to the project directory:
   ```bash
   cd PixArc
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development

Run the development server:
```bash
npm run dev
```

### Building for Production

Create an optimized build:
```bash
npm run build
```
